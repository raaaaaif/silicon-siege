# Assets and attribution

`web/assets/pixel-world.png` contains the circuit-island background. `web/assets/pixel-agents.png` contains a four-column, three-row sprite atlas. Both were generated with OpenAI image generation for this project. No reference game assets were used. CSS selects animation frames with integer steps. Diagrams and charts use HTML and SVG.

The art uses a limited navy, teal, mint, cream and copper palette with flat pixel shading. The interface supports a schematic view alongside the illustrated view.

Space Grotesk is served locally under the SIL Open Font License. Its license is included in `web/assets/FONT-LICENSE.txt`.
