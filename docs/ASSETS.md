# Original visual assets

Generated with the built-in OpenAI image generation tool. The accepted direction is restrained late 8-bit / early 16-bit pixel art. No reference game assets were copied. `web/assets/pixel-world.png` is the circuit island; `web/assets/pixel-agents.png` is the 4-column, 3-row animation atlas. CSS selects each frame with integer steps. The interface, diagrams and charts remain native HTML/SVG.

## Background prompt

Use case: stylized-concept. Asset type: original pixel art background for a browser chip-building strategy game. TRUE pixel art, restrained late 8-bit / early 16-bit top-down adventure game aesthetic, slightly more refined than an original NES adventure game. NOT 3D NOT realistic NOT voxel NOT painterly NOT cinematic NO smooth gradients NO bloom. A top-down small island made of a dark teal printed circuit board, floating in an almost-black midnight background. Clean square pixel clusters, limited palette of about 16 colors (deep navy, blue-teal, muted mint, warm cream and rusty copper). Simple readable square ceramic chip modules, little square memory-bank buildings, copper traces drawn as paths, two tiny flags, tiny round orange signals. Broad EMPTY dark-teal central square plaza with very subtle tile grid, intended for an interactive game grid overlay. Overall composition centered in a landscape 3:2 frame, symmetrical but charming handcrafted details. Small amount of moss growing at the corner, technical little components rendered like fantasy adventure buildings. Crisp hard pixel edges, simple readable silhouettes, 2-3 flat shading levels only. Top down orthographic, no isometric perspective. Spare, tasteful, calm, nostalgic, a game made by a thoughtful indie developer, not overproduced. Empty surrounding background. NO text NO letters NO UI NO logo.

## Sprite prompt

Use case: stylized-concept. Asset type: transparent pixel art game sprite sheet. TRUE restrained late 8-bit early 16-bit top-down adventure sprites, crisp chunky square pixels, 16 color palette, simple charming shapes with 2 flat shading levels. NOT 3D NOT realistic NOT Pixar NOT toy render NOT anime. Exactly 3 rows and 4 columns, twelve evenly-spaced sprite cells of equal size on a genuinely transparent background. Each row contains four consecutive animation poses of ONE character, all consistent scale. Row 1: small friendly ivory rectangular chip robot with two teal eyes, small copper antenna, navy feet, mint scarf, four walking/idle poses. Row 2: squat mint and ivory beetle-like verification bot with a simple shield body and dark visor, four walking poses. Row 3: small mischievous rust-orange glitch crab with dark navy shell and two orange eyes, four walking poses. Tiny game sprites each appears about 32x32 chunky art pixels, lots of transparent padding around each, never touching cell boundaries. Strong clear silhouette and simple readable personality. Flat limited colors, no shiny material, no 3D shadow, no outline glow. No words no letters no labels no scenery no ground shadow.
